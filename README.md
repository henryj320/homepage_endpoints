## clamav_homepage

**Title**: sftp_checkup_homepage

**Date Started**: 2024-04-16

**Date Completed**: 2024-04-27

**Language**: Python

**Overview**: Sets up a FastAPI to control a custom widget on Homepage. This API returns the status of:

- File Browser
- FolderSync (Henry and Poppy's)
- IP Checker

**Result**: An API with the following endpoints has been set up: "/Henry", "/Poppy", "/filestore", "/update-ip".

## Running the Project

- Simply ` cd ` into the directory and run ` docker compose up -d --force-recreate --build `.
